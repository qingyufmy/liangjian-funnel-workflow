# A1-A4 行为类型、情绪周期与多空环境改造验收

日期：2026-09-01
代码基线：`d83de613f34e5c117921bfe06f42ac4df92a0756`
输入：现有 A1-A4 实现、既有三策略合同、《选股核心思路》评审结论、《短线情绪票》实践补充。
边界：本报告仅为本地工程验收；未部署、未重跑生产 A1-A3、未连接真实交易，不能据此宣称策略收益有效。

## 1. 附件实践与原项目的差异结论

### 1.1 原项目已具备

- A3 已有龙头、趋势 5 日线、520 三条互斥技术路线。
- A3 已有日线派发、趋势过度延伸、MA20/死叉、弱日线和风险市场阻断。
- A4 已按策略分别使用 15m/5m 进行入场、加仓、减仓和退出判断。
- 市场事实层已有涨跌停池、炸板池、连板梯队和全市场涨跌广度。

### 1.2 原项目缺失或不完整

- A2 只有市场角色，没有稳定、互斥且可追溯的 `EMOTION/TREND/UNRESOLVED` 行为类型。
- A2 的角色与 A3 策略之间没有不可绕过的路由合同，模型合并后存在类型漂移风险。
- 市场情绪只有温度，没有“冰点—启动—确认/加速—高潮—分歧/退潮”的新开许可。
- A3 的周期与持有期信息不完整，计划无法直接说明属于 1-3 日情绪路线还是 1-3 周趋势路线。
- A4 只校验策略名，不二次校验股票行为类型，错误路线理论上仍可能进入执行器。
- A1 的月度产业结构与 20 日时点混在一个决策里，短期降温可能误删仍成立的产业周期。
- 财务负增长曾可能被绝对值处理，造成估值成长方向错误。
- 巨潮风险事实实际按 `by_symbol` 落盘，而旧筛选器只读取 `records`；这会让重大减持等权威负面事实静默漏检。
- 原市场环境没有区分“成交额扩张的增量趋势”与“成交额平稳的存量轮动”，也没有把这一判断的覆盖率和可比股票池落盘。

## 2. 已落地的确定性合同

### 2.1 A1

- 新增公司原型：`CYCLICAL_UPSWING/GROWTH_TREND/DEFENSIVE_QUALITY/UNCLASSIFIED`。
- 新增回撤成因：`SYSTEMIC/STRUCTURAL/FUNDAMENTAL/UNKNOWN`；确认的基本面恶化继续硬拒绝。
- 财务事实输出覆盖率、缺失项和负增长原值；缺失不补零，负增长不取绝对值。
- 月度产业决策拆为 `structural_status` 与 `timing_state`；结构仍有支撑但 20 日降温时改为等待时点，不从研究域删除。
- 风险事实读取同时支持 `records` 与 `by_symbol`，并保留股票、事件类型、标题、严重度、发布时间、来源 URL/ID 和事实 ID；`大幅减持/重大减持` 进入可回溯硬风险词典。

### 2.2 A2

- 每只股票确定为 `EMOTION/TREND/UNRESOLVED`，输出六维证据、数据缺口、已知负面、冲突与允许策略。
- 明确连板/梯队锚点时，最短周期行为优先归为 `EMOTION`；同一公司即使中期趋势良好，也不同时走两套交易技术。
- 没有情绪锚点且中期趋势、相对强度、产业逻辑均确认时为 `TREND`。
- `UNRESOLVED` 仍可留在 A2 研究面，不因数据缺口伪装成“市场无机会”；但不能由 A3 发布计划。
- 拥挤度当前仍标记 `PARTIAL_PROXY_ONLY`，龙虎榜/热度不能冒充基金持仓、两融与换手结构。

### 2.3 市场情绪与多空环境

- 复用现有市场温度，无新增综合分：
  - `ICE -> ICE_POINT/NO_NEW_ENTRY`
  - `WEAK -> RETREAT/NO_NEW_ENTRY`
  - `DIVERGING_WEAK -> DIVERGENCE/NO_NEW_ENTRY`
  - `OVERHEATED -> CLIMAX/NO_NEW_ENTRY`
  - `STRONG -> CONFIRMATION|ACCELERATION/ALLOW_CORE`
  - 修复期且梯队种子出现 -> `IGNITION/PROBE_ONLY`
  - 无法确认 -> `MIXED/WATCH_ONLY`
- 市场环境仅分为 `BULL_TREND/ROTATION_MIXED/BEAR_RISK`。它是执行上下文，不是选股总分。
- 高潮、分歧、退潮、冰点只阻断新的情绪龙头路线，不误伤独立成立的右侧趋势计划。
- 新增同一可比股票池的近 5 个完整交易日成交额代理：`INCREMENTAL_EXPANSION/EXISTING_FUNDS_ROTATION/LIQUIDITY_CONTRACTION/UNRESOLVED`。它明确标注“成交额不是资金净流”，只进入 A2/A3 的市场环境溯源，不直接形成选股或交易门。
- 最新交易日覆盖不足时禁止回退到旧交易日冒充；涨跌广度、基线和可比池覆盖任一不足即为 `UNRESOLVED`，而不是“真实无机会”。

### 2.4 A3/A4

- A3 1.3 合同：
  - `EMOTION` 只能对应 `LEADER_INTRADAY`；
  - `TREND` 只能对应 `TREND_MA5/MA520_SWING`；
  - `UNRESOLVED`、类型冲突或权限非 `ALLOW_A4` 不发布计划。
- 计划保存行为类型、路由权限、形态、市场环境、情绪周期、预期持有期和时间止损。
- 默认期限：龙头 1-3 日/3 日时间止损；趋势 MA5 3-10 日/7 日时间止损；520 5-20 日/7 日时间止损。
- 模型只能否决或指出数据缺口，不能改类型、策略、价格、期限或路由权限。
- 计划发布器和 A4 执行器二次校验行为—策略兼容性。1.2 历史计划保持兼容；1.3 新计划缺字段或冲突即阻断。
- A4 在当前市场为风险收缩环境时只阻止新入场，不影响已有持仓按原策略执行退出；情绪周期 `NO_NEW_ENTRY` 也只约束龙头路线。

## 3. 顶部、行情环境与数据边界

- 情绪顶部的快速风险已由题材高潮/退潮、梯队断裂、派发和盘中龙头退出规则覆盖。
- 趋势顶部的慢速风险已由放量长上影派发、日线弱势、MA20/MA60、死叉和过度延伸边界覆盖。
- A3 现分别持久化 `behavior_risk.emotion_top` 与 `behavior_risk.trend_top`；只有冻结 K 线标签、确定性派发或明确技术上下文可确认，模型自由文本不能升级为服务端硬风险。
- A4 对匹配类型的已确认顶部风险执行：无持仓取消入场，有持仓走对应策略退出；不会把情绪顶部错套到趋势票，反之亦然。
- 头肩顶、三重顶、箱体破位等复杂形态没有在本轮凭文字直接硬编码；需要先由日线聚合器产出点时可回放结构，再以样本验证决定是否成为硬门。
- 熊市/退潮中的反弹不能直接改写为趋势启动。A3 必须先有日线右侧结构，A4 再以闭合 15m/5m 确认。

## 5. 复审一：删除过度设计

- 未新增统一选股总分、情绪总分、Redis、向量库或额外模型轮次。
- 情绪周期直接映射现有温度事实，避免两套阈值同时漂移。
- 没有实现未经样本验证的复杂形态识别器。
- A1/A2 只新增纯确定性分类模块；不在分类模块里做网络请求、排名或交易。
- 持有期是计划合同，不参与选股分数。

## 6. 复审二：异常与边界

- 数据缺失、已知负面和事实冲突保持三种不同状态。
- 新行为合同通过版本号启用，旧回放不会因新增字段突然失真。
- A2 类型未定不会把股票从研究域抹掉；A3/A4 执行域则保守阻断。
- A3 风险收益或止损距离后置失败时，会同步把 `route_permission` 改为 `BLOCKED`，避免状态互相矛盾。
- 模型输出即使篡改类型或策略，也会被谱系 canonicalization、A3 发布门和 A4 执行门三次纠正/阻断。
