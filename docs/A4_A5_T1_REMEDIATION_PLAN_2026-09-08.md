## 1. 必须纠正的认识和交付边界

普通现金账户中的 A 股，当日买入股份不得当日卖出；止损、强制风控、模型建议均不能例外。以前交易日买入且已可卖的股份，不因今日另有加仓而全部变为不可卖。限制落到股份数量及其取得日期，不是简单判断“这只股票今天是否买过”。规则依据见第2节。

9月8日伯特利实际模拟账本遵守了T+1，没有同日卖出。本次确认缺陷是技术状态、退出汇总及通知没有一致表达这一限制，而不是已经发生了违法卖出。整改不能只改中文标题：必须证明所有进入模拟撮合的路径都受同一可卖校验约束。

现有三策略文档第284、359、643行已要求当日新买只记录风险、不得伪造卖出；第496行明确T+1由执行层处理，不交给模型决定。方案遵循此职责，不把T+1改成模型评分或让模型决定放行。

本轮仅编制方案。后续实施按批验收；不调整入场条件、止损价、盈亏比、策略路由或模型主路径，不新增真实交易，不为修复展示重跑A1，不重写原始事件。生产状态引用9月8日已冻结诊断，不把15:48的状态冒充未来任务的当前状态。

## 4. 目标结构：三个维度独立记录

```text
策略技术事件（触发了什么、事实是什么，不保证可交易）
            ↓
执行资格（T+1／可卖数／时段／证券状态／风险与价格校验）
            ↓
模拟委托与成交（待成交／部分成交／完成／撤销／未成）
            ↓
持仓账本 → 生命周期 → 飞书及页面 → A5与T+N
```

这是顺序关系，不能让“技术触发”跨过执行资格直接更新资金或已实现收益。最终资格校验必须由服务端确定性代码执行；LLM只能解释或在既有授权边界内复核，不决定可卖数。

### 4.1 拟议字段及兼容方式

在既有事件／生命周期的可扩展元数据内先增加字段；若必须新增列，采用增量schema版本并测试旧读者，不直接破坏已有枚举。

| 对象 | 拟议字段 | 含义 |
| --- | --- | --- |
| 技术事件 | `technical_action / technical_reason / reference_price / decision_at` | 风险事实及价格，原事件不可变 |
| 资格快照 | `total_qty / settled_qty / today_buy_qty / reserved_sell_qty / available_sell_qty` | 区分已结算、当日锁定与未成委托占用，避免重复扣减 |
| 资格结论 | `execution_eligibility / blocked_reasons / earliest_sell_session / rule_version` | 不可卖、部分可卖、可提交；最早交易日不保证成交 |
| 退出任务 | `first_exit_event_id / highest_priority_event_id / latest_observation_id / exit_scope_id` | 首次触发、最强未完成风险和最新观察分别保留 |
| 数量目标 | `target_exit_qty / executed_exit_qty / remaining_exit_qty / eligible_now_qty` | 目标不是可卖量；可卖0不等于目标退出0 |
| 执行结果 | `intent_id / attempt_id / fill_id / order_status / fill_price / filled_at` | “具备卖出资格”不是成交，失败与未成交不能造资金变化 |
| 时点 | `decision_at / persisted_at / sent_at_actual / market_as_of` | 决策、写库、实际投递与行情时点分开 |

数量信息不完整时记未知并阻断执行，不能用总持仓兜底成可卖数量。`_sellable`中从quantity回退的路径需纳入检查。已有position单行聚合表可保留；取得批次与解锁数量优先从成交账本派生并缓存，避免无依据重建全部历史库。

### 4.2 必须成立的不变量

1. `0 <= available_sell_qty <= settled_qty <= total_qty`；有效挂单占用不能重复计入可卖。
2. 当日买入／加仓的新增数量，不能由重启、重复开日、午休或日历错误变成当日可卖。
3. 单次拟卖数量不能超过当时可卖；累计卖出不能重复消耗同一批股份；强制风险退出同样受限。
4. 风险事件不更新已实现收益；只有幂等成交与账本事务能更新持仓和现金。
5. 未退出的较强风险任务不被后续较弱减仓事件覆盖；原始事件始终可查。
6. 新A3未收录或原计划到期，不自动关闭持仓及其风险监控；无持仓的过期买入计划不因此复活。
7. 昨日委托与跨日风险任务不同；次日新的执行尝试仍关联原风险任务，并接受当日交易限制。
8. 模型输出、展示分组及A5建议均不能改变以上不变量。

风险预算口径：当前以止损距离计算仓位只能表达计划风险，不能承诺最大实际亏损。新买当日无法退出、隔夜跳空及流动性不足都可能扩大损失；A5必须记录制度锁定期间风险、首次风险价至实际退出的差异和未实现损益，不能用当日止损价虚构可实现收益。是否因此调整入场风险预算属于策略研究，不在本批自动改参数。

## 7. 冻结回放、历史数据和上线顺序

### 7.1 验证分层

1. **原引擎基线**：冻结9月8日事件、26计划、逐时行情、市场快照、模型响应、策略／提示词／源码哈希及费用参数；37抽样扩到5,810记录全日比较前，先补齐各时点所需状态证据。

5. **跨日组**：以既有真实后续历史样本或明确标注合成行情验收，不制造尚未发生的9月9日真实行情。下个自然交易日只读核验真实表现。

## 9. 最终完成标准

任何普通A股当日买入股份都不能被系统同日卖出；当日触发风险必须清楚说明未执行原因。后续可卖不代表必成交，真实执行条件、原风险来源和资金数量始终可审计。A5基于这些事实复盘，不因任务运行成功就认定策略健康，不以错误落层指导放宽选股。只有逐批测试、冻结对比及上线核验完成后，才将对应任务标为完成。
