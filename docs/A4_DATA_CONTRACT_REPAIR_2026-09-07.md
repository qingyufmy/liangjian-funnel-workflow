# A4 行情口径及版本修复

## 本次实施

1. 腾讯股票分钟线成交量从手乘100换算为股；通达信保留股。两源均显式标注单位及解析版本。腾讯成交额仍是OHLC均价估算，明确标为估算；通达信为报告值，不宣称两源成交额、成交量或所有OHLC完全相等。
2. 通达信股票分钟线13:00午间结束标签规范为11:30，原标签另存。依据9月7日40只股票、1分钟/5分钟独立对照；若同时出现11:30和13:00导致重复，拒绝该批，不默默丢弃冲突。适配仅限当前标准股票分钟接口。
3. 新增完整行情版本表和压缩的决策快照表，自动建表且不覆盖旧表。保存来源、解析版本、完整数值、真实记录时间、决策截止时间及内容哈希。原分钟表保留最早值作为历史证据。
4. A4使用当前决策已经持久化的行情快照；后续抓到的修订可用于下一次决策，同一分钟重试继续使用首次选定快照。快照缺失、截止时间错误、哈希错误或写入失败均阻断执行，不绕过落盘直接用内存行情。
5. 显式归档修订同样保存修改前后完整值；旧记录最初获知时间未知时仅记当前捕获时间，不虚构历史时间。
6. A5优先读取事实截止前本交易日最新决策快照，带快照标识和哈希；没有新快照的历史交易日明确标注使用最早归档。最新快照用于截止时点独立核验，不冒充更早每一分钟的原始判断。

## 边界

不改三类策略或入场门槛，不补发停机期间交易信号，不覆盖9月7日原始记录。旧库只有冲突哈希的历史修订无法从哈希恢复完整数值；现有封存采集与全日回放仍属于盘后证据，不能冒充当时已知数据。

快照表示“本次已结束K线的实际观察版本”，不保证公开行情源此后不再修订，也不以两次返回相同就宣称最终定型。新版本只影响后续判断。

已有停机、任务停滞、漏执行及恢复飞书告警继续由Windows独立探针负责；保持Windows开机并登录。不会为了清除今天历史漏执行告警伪造完成记录。

快照采用压缩存储、版本按完整内容去重；暂不自动删除历史证据，需按真实增长持续检查磁盘容量。新增表由现有应用初始化创建，不需要人工数据库修复脚本。

## 两轮检查

- 第一轮：核对原始采集、源适配及消费路径，确认“最早缓存值永远胜出”造成修订无法进入后续分析。
- 第二轮：检查时间因果和重复执行；分开真实捕获时间与决策截止，保留旧数据，按决策冻结选择，并在持久化失败时维持阻断。

验收覆盖单位换算、原标签留存、重复标签拒绝、后续修订、重复决策冻结、异源独立留存、未来K线排除、快照哈希损坏及显式修订原值留存；部署结果另行记录。
