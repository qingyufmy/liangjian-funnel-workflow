# 免费数据源板块轮动替代方案

## 1. 决策

不再等待或依赖付费的同花顺801精选板块接口，也不再要求系统结果复现同花顺手机端的非公开强度值。

新的生产口径定义为：

> 使用东方财富、腾讯、通达信免费数据，按照固定板块映射、固定成分和公开公式计算“量见板块强度”；在资金净流入为正的一级方向中取前5，子方向继承父方向排名但不重复占位。

输出必须明确标为“量见板块强度”，不得再显示或暗示为“同花顺801精选板块强度”。同花顺截图仅作为异源观察样本，不作为生产真值。

本方案不降低 A1 主营和基本面要求，也不改变东方财富前100作为情绪源的独立地位。

## 2. 免费数据实测

核验时间：2026-09-04，Asia/Shanghai。

| 数据源 | 实测结果 | 适合承担的角色 | 不能承担的角色 |
|---|---|---|---|
| 东方财富 | 行业资金榜496条，其中正流入216条；概念资金榜504条，其中正流入183条 | 板块目录、板块资金、当前成分、逐股成交和资金复核 | 不能冒充同花顺801；历史成分需自行每日归档 |
| 腾讯 | 贵州茅台、中际旭创、紫金矿业等样本均能返回主力净额和大单净额 | 逐股主力资金主源、行情复核、按内部板块聚合资金 | 响应本身缺少明确交易日，必须与固定采集时点和同日行情绑定 |
| 通达信公共节点 | 4个节点中1个可返回19根完整闭合1分钟/5分钟K线，3个节点请求失败 | K线、均线、涨跌幅、量价结构的独立主/复核源 | 节点波动较大，不能作为唯一生产源 |

东方财富的板块成分接口还存在单页最多100条的情况。例如 AI应用板块实测总成分282只，必须分页抓全，不能把第一页误当成完整成分。

## 3. 数据源职责

### 3.1 东方财富

负责：

- 行业和概念板块目录；
- 板块当前成分股；
- 板块当日主力净流入和涨跌幅；
- 成分股成交额、涨跌幅和主力净额的复核；
- 东方财富股吧人气前100情绪源。

目录与成分是慢变参考数据：首次完整采集后版本化落地本地，默认每7天全量刷新一次；达到7天时标记陈旧提示，14天内更新失败可继续使用最后成功版本并告警，超过14天则对应趋势通道失败关闭。资金和行情仍按每个交易日重新采集冻结。从首次正式运行日起形成点时历史，回放只能使用在目标交易日之前已经采集并生效的成员版本，禁止使用未来版本倒填。

### 3.2 腾讯

负责：

- A股逐股主力净流入；
- 大单、超大单资金结构；
- 个股最新价与分钟行情复核；
- 按“量见板块成分”重新聚合板块资金。

腾讯是自研板块资金的主计算源。东方财富板块净流入只作同方向复核，避免一个供应方同时决定成分、强度和资金。

### 3.3 通达信

负责：

- 日线、1分钟、5分钟闭合K线；
- MA5、MA20、MA60、量价趋势和板块成分广度；
- 与腾讯/东方财富收盘价交叉核验。

至少配置4个公共节点并持续健康探测。通达信全部不可用时，日终强度可以使用腾讯/东方财富闭合行情降级完成；A4盘中仍按现有实时行情失败关闭规则执行。

## 4. 固定的“量见板块体系”

新增版本化板块注册表 `LIANGJIAN_ROTATION_THEME_V1`，而不是每天根据板块名称临时聚类。

每条注册记录包括：

```text
theme_id
theme_name
theme_level: PRIMARY | CHILD
parent_theme_id
eastmoney_board_codes[]
board_name_aliases[]
included_industries[]
excluded_aliases[]
effective_from / effective_to
mapping_version
review_evidence
```

首批一级方向沿用已确认的月度成熟映射，包括但不限于：AI算力基础设施、半导体国产化、消费电子、国防军工、机器人、化工、有色金属、贵金属、非金属材料、金融保险、农业、创新药医疗、电力设备新能源、消费服务和航运。

子方向包括液冷、CPO、先进封装、培育钻石、AI应用等。液冷作为AI算力子方向；贵金属、有色金属分别保留独立身份。经2026-09-04业务确认，免费数据体系中的金刚石相关表述统一映射到东方财富培育钻石板块 `BK1023`，不再保留无公开代码的独立占位。

一个股票可以属于多个方向，但同一一级方向内必须按股票代码去重。注册表只能通过带证据的版本升级修改，日度任务不得让模型自动改映射。

## 5. 透明强度公式

先计算每个一级方向的六项横截面分位数，均为0—100分：

| 因子 | 权重 | 计算方法 |
|---|---:|---|
| 当日相对收益 | 25% | 成分股等权中位涨跌幅相对全市场，做横截面分位 |
| 上涨广度 | 20% | 上涨家数比例与站上MA5比例各占一半 |
| 主力资金 | 25% | 腾讯逐股主力净额合计/成分股成交额合计，做横截面分位 |
| 三至五日动量 | 15% | 成分股3日和5日相对收益的稳健均值 |
| 龙头与涨停结构 | 10% | 涨停比例、连板高度、前10%强势股贡献，避免只看平均数 |
| 排名持续性 | 5% | 最近3个交易日进入前10的次数和排名改善 |

公式：

```text
量见板块强度 =
25%×当日相对收益 + 20%×上涨广度 + 25%×主力资金
+ 15%×三至五日动量 + 10%×龙头结构 + 5%×排名持续性
```

进入前5的硬条件：

1. 腾讯逐股聚合主力净额大于0；
2. 资金覆盖达到该板块可交易成交额的80%以上；
3. 行情覆盖达到可交易成分股的90%以上；
4. 板块成分非空且快照交易日正确；
5. 综合强度按一级方向降序取前5；
6. 子方向只继承父方向名额，并单独显示子方向强度和资金。

前10日先使用上述阈值做影子验证，阈值只能基于覆盖稳定性调整，不能因为某日少票而放宽。

## 6. 跨源核验和冲突处理

| 场景 | 处理 |
|---|---|
| 腾讯聚合资金为正，东方财富对应板块也为正 | 正常，通过资金复核 |
| 腾讯为正、东方财富为负 | 标记资金冲突；可进入观察，不进入前5聚焦 |
| 腾讯覆盖不足，东方财富完整 | 只作观察，不用东方财富单源强行晋级 |
| 通达信不可用，腾讯与东方财富收盘价一致 | 日终降级计算，记录行情降级 |
| 三源价格明显冲突 | 该股票不参与当日板块强度，触发数据告警 |
| 东方财富板块目录/成分缺失 | 对应方向失败关闭，不用名称猜成分 |

不同供应方的板块分类不完全相同，因此只有注册表中明确一对一映射的东方财富板块才能参与资金正负复核；宽泛主题不得强行比较。

## 7. 每日时序

1. 15:05—15:10：抓取东方财富行业/概念资金榜；板块目录和完整分页成分仅在本地版本到期时刷新，否则读取未超龄的最后成功版本；
2. 15:10—15:20：抓取腾讯逐股资金与行情；
3. 15:20：抓取通达信闭合日线/分钟线并做价格复核；
4. 15:25：按固定公式生成量见板块强度和正流入前5；
5. 15:30：完成A1月度池与前5板块成分交集，生成A2趋势通道；
6. 同时独立处理东方财富前100情绪通道；
7. A1/A2/A3 containment通过后原子激活收盘结果；
8. 16:00前未完成则发送飞书阻断告警。

日变数据写入不可变日快照；慢变的目录与成分写入不可变版本快照并维护有效期索引。两类数据均分别保存来源、抓取时间、交易日或生效日、记录数和内容哈希。

## 8. 飞书告警

新增：

- 东方财富板块榜不可用/不完整；
- 东方财富成分页缺失；
- 腾讯资金覆盖不足；
- 通达信节点池全部不可用；
- 腾讯与东方财富资金方向冲突；
- 跨源收盘价冲突；
- 量见板块强度未能在16:00前生成；
- 数据恢复。

告警按“交易日+数据源+原因”去重，恢复只发送一次。

## 9. 对现有代码的调整

1. 将 `selected_board.py` 的801专属合同改造为通用 `rotation_theme_snapshot`，保留旧结构仅用于历史兼容；
2. 新增东方财富板块目录和完整分页成分采集器；
3. 新增腾讯逐股资金聚合器；
4. 新增固定公式的板块强度计算器；
5. 把成熟主题注册表扩展为东方财富BK代码与内部父子主题的版本化映射；
6. A2趋势通道读取“量见正流入强度前5”；
7. A2情绪通道继续独立读取东方财富前100；
8. 导出统一显示中文的“量见板块强度、资金净流入、一级排名、子方向”，不展示内部英文枚举。

## 10. 验收

固定回放和每日影子运行必须证明：

- A1、A2、A3集合关系100%成立；
- 每个前5方向都能追溯到公式六项输入；
- 每只趋势候选都属于当日冻结成分；
- 子方向不重复占用一级前5名额；
- 前100情绪票不再被月度主营证据误伤；
- 任一免费源失败时明确降级或关闭，不伪造完整数据；
- 连续10个交易日记录完整率、源冲突率、榜单变化和与外部截图的方向重叠，但不要求复制同花顺分值。

## 11. 两轮复核

### 第一轮：业务复核

初步方案仍试图用东方财富或腾讯的某个单一板块榜替代801，这会重新引入供应商黑箱和分类漂移。调整后不采用任何单一供应商“强度”，而是基于固定内部板块和公开六因子公式生成自有强度；外部板块榜只提供事实输入和复核。

### 第二轮：工程复核

初步方案没有充分处理东方财富板块重复层级、成分分页和通达信节点不稳定。调整后要求内部父子注册表、板块内股票去重、全部分页完成性、通达信多节点健康池和腾讯/东方财富降级路径；历史回放禁止用今天的成分倒填过去。

## 12. 剩余风险

- 免费网页接口可能变更字段或增加反爬；必须通过适配器、快照和告警隔离；
- 通达信公共节点经常变动，需自动探测和补充节点；
- 东方财富只能保证从正式归档日起拥有点时成分，更早历史不能伪造；
- 腾讯逐股资金缺少明确交易日字段，必须在固定收盘窗口采集并与同日行情交叉确认；
- 自研强度与同花顺截图不必相等，验收目标是透明、稳定、可重放，而不是拟合某一天的榜单。
