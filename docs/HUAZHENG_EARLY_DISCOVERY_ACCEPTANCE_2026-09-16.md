## 1. 本批实现

| 环节 | 修改 | 不变的边界 |
| --- | --- | --- |
| 早期发现 | 闭合日线识别修复观察、5/20均线金叉准备、趋势重启；事件继续观察最多10个闭合交易日，跌破20日均线失效，不复活已失效旧事件 | 仅线索，不是买点；不使用未来日线、不接受未知或混合复权口径 |
| 数据入口 | 复用A1的盘后任务先刷新全市场研究范围日线；逐只扫描完整本地历史，再压缩为原有30根快照 | 不重跑全市场A1模型，不批量重拉全市场财报；扫描额外日线请求属于必要的数据刷新成本 |
| 盘前入口 | 全市场仅扫描最近已收盘交易日的本地缓存，缺失/过期明确记录；预算内线索进入当日证据准备范围 | 不在竞价时启动额外全市场网络扫描；不替换既有A4计划 |
| A1 | 池外线索按原有月度方向、主营证据和已披露半年报规则复核；通过后形成带证据哈希和日期的日度增量 | 不修改月度/周度密封主池；缺证据不绕过A1，不以技术强势代替基本面 |
| A2 | 情绪身份与趋势资格分开；板块前五之外增加最多30只强趋势补充研究观察 | 保留板块前五；补充观察禁止自动开仓；硬风险、基本面、辨识度及数据条件不放宽 |
| A3 | 对具有独立资格的策略分别计算并保留检查结果，最终仍只选择一个策略计划；准备观察进入观察池，不再一律显示淘汰 | 未满足策略结构、数据不足、风险禁止仍分别保留；首板观察不删除合格趋势研究结果 |
| A4发布边界 | 明确阻断强趋势补充观察的正式计划发布；继承上游禁止开仓权限 | 实际分钟确认、盈亏比、止损、T+1、模拟成交规则不变 |
| A5/通知证据 | 保留独立策略检查与观察权限，补充中文原因 | 不补发历史信号，不把研究观察写成实际成交 |

每日证据复核预算为100只；溢出线索仍留在审计中，不伪装为技术淘汰。它不是股票数量目标，也不保证每天一定有100只或30只。

新增代码：`pipeline/early_discovery.py`；只读检查入口：`scripts/audit_early_discovery.py`。同步修改A2/A3提示词及量化版本，避免提示词仍要求情绪/趋势互斥。
