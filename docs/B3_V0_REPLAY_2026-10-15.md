The original frozen `strategy.live_entry_price`, where present, is supplied only as the scalar used by live geometry. It is explicitly labelled `FROZEN_KERNEL_LIVE_ENTRY_PRICE_NOT_FULL_QUOTE`. This is **not** proof of a complete quote, exchange arrival or executable fill.

## Implementation and input contract

- `src/liangjian_funnel/evaluation/b3_baseline.py`: `iter_frozen_windows(state_db, minute_db=None, market_state_root, trade_dates=None)` yields one `WINDOW`, `PRE_KERNEL_BLOCK`, `GAP` or `NON_STRATEGY` row at a time.
- `WINDOW`: original plan and row; `tuple[MinuteBar]`; 5m bars; frozen market context; aware observation/dispatch clocks; original event and verdict; event/plan/snapshot/market hashes.
- Snapshot validation reuses `evaluation.ablation.exporter._snapshot`; clock and market-gate reconstruction reuse the existing frozen A4 audit helpers. A metadata-only in-memory rowid index avoids altering the exported SQLite source.
- No complete day bar graph is accumulated. Episode history retains only the fields read by the actual monitor deduplication function, not large original payloads.
- Plan validity uses database target expiry and original activation. A later `INVALIDATED` status or `updated_at` is never used to erase legitimate earlier rows. Coverage termination requires an original `PLAN_INVALIDATED` event.
