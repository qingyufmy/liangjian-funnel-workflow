# A4 独立运行告警

## 已实施范围

探针在Windows运行，通过已有`aurum-vm` SSH别名只读检查虚拟机。不会启动研究、修改数据库、重启服务或补发交易。

覆盖远端无法探测、应用健康异常、A4任务超过90秒未完成应执行分钟、重启后历史执行缺口、盘前/早盘/午间/盘后任务超过恢复窗口未完成，以及故障恢复。

使用交易所日历，不把周末、节假日或午休当成缺失交易分钟。事件去重导致某一分钟没有新事件时，还会结合Node业务调度成功日志；仅进程返回0但没有执行业务不算完成。

## 运行与状态

- 任务名称：`Liangjian-A4-External-Watchdog`。
- 脚本：`scripts/watch_a4_runtime.py`。
- 运行频率：每分钟一次，单实例、隐藏窗口、最多55秒。
- 交易日08:20—20:40执行远端探测，其他时间跳过远端探测。
- 只读检查：`.venv\Scripts\python scripts/watch_a4_runtime.py --dry-run`。
- 明确标记的安装测试：`.venv\Scripts\python scripts/watch_a4_runtime.py --test-notification`。
- 安装/更新：`powershell -NoProfile -ExecutionPolicy Bypass -File scripts/install_a4_watchdog.ps1`。
- 卸载：上述命令末尾增加`-Uninstall`，不会删除审计账本。
- 最近检查：`state/a4_watchdog/latest.json`。
- 故障及投递账本：`state/a4_watchdog/watchdog.sqlite3`。
- 飞书配置：`state/a4_watchdog/lark_webhook.json`，已排除版本控制，文件权限限当前管理员与SYSTEM。

## 投递约定

同一次故障只发送一次告警和一次恢复提醒；发送失败保留待重试，退避上限15分钟。故障通知未成功前，恢复通知不能越过它。传输采用至少一次语义：若进程恰在飞书成功后、本地事务提交前退出，可能重复一条消息，不能承诺外部严格一次。

新发现但已经恢复的历史执行缺口单独提示，只用于复盘；不会伪造停机时实际发出的告警。今日手动重启原因已经用户确认，缺口告警不代表自动判定主机崩溃。

## 生效限制

Windows必须开机且当前用户保持登录；该任务使用当前用户的SSH身份，不存储Windows密码。锁屏可运行，注销/休眠/关机不可运行。如果Windows同时也是虚拟机宿主机，整台物理机断电仍是共同故障点。需要覆盖这种场景，应把同一探针迁到另一台持续在线设备。

飞书地址在独立探针本地保留一份；主应用更换机器人后，应同步更新该受保护文件。主应用代码部署与该独立探针分别验收。
