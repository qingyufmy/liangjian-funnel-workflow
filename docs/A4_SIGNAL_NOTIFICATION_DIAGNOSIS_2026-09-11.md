## 二、已实现的消息边界

| 类别 | 处理 |
|---|---|
| 入场前计划失效、普通模型否决、等待、预热、空范围 | 不逐只推送；原始事件完整落盘，A5统一解释 |
| 买入/加仓条件触发且冻结执行契约就绪 | 保留，明确价格、风险和待成交状态，不把触发当成交 |
| 买入/加仓记录缺少就绪执行契约 | 作为数据告警，不包装成交易机会 |
| 已持仓离场、减仓、强制风险退出 | 保留，明确T+1可卖约束及尚未成交状态 |
| 行情或系统故障 | 保留独立告警及既有去重；不随普通失效通知一起关闭 |
| 已发信号的模拟成交/未成交回执 | 保留，用于澄清是否真正建立持仓 |

不把 `effective` 改成false，也不删除状态机事件，从而保留终止、去重、原始复盘和T+N证据。A5新增独立交易触发数量、计划失效数量；原业务状态事件数继续保留，不再把失效数称作交易信号数。历史未单独统计的数据明确显示缺项，不伪造零。

## 三、高质量信号不能只靠关闭消息

四个计划全属于非银金融，研究资格通过不等于方向分散，也不等于次日有买点。此次同向风险集中已经暴露，入口质量应继续围绕以下可验收事项改进，而不是降低止损或保证每天有买入：

1. **A2按真实成员检查覆盖。** 单独列出每个入选板块的A1数量、量化通过数、A3通过数。银行方向上游为0，不能声称该方向已经获得有效股票覆盖，也不能用证券股替代银行股。
2. **A3检查交易路径的可达性。** 技术资格之外，展示参考区间、真实风险线/压力位、达到既定盈亏比的实时价格上界、是否需要特殊回踩路径。静态参考区间不满足盈亏比时明确条件尚待成立，不包装成马上可以买的机会；不能因此直接伪造更远目标价。
3. **A4只对完整触发提醒。** 同时具备闭合周期技术确认、实时价格纪律、有效数据和冻结执行契约。高质量指条件明确且可执行，不是对盈利或每日信号数量的保证。
4. **按信号而非消息衡量效果。** 分别记录触发、模拟成交、未成交、当日表现、T+N、最大有利/不利波动；失效计划保留负样本，不混入买卖信号或成交收益。

上述入口及策略质量改进中，尚未验证的规则变更不在本轮自动发布；尤其不能仅凭4只同跌把合理结构失效改成继续追踪开仓。
