# A1-A3 覆盖、轮动与次日计划改造方案（2026-09）

## 目标

把研究漏斗从“重复硬过滤”调整为三层职责清晰的系统：

1. A1 负责月度研究覆盖，不负责给出次日买点。
2. A2 负责识别截至当日的板块与题材轮动，保留强度 TOP3 的多方向候选。
3. A3 负责把候选匹配到三类可执行的次日技术计划，A4 再使用 5/15 分钟闭合行情确认入场或离场。

数量是容量验收指标，不是强制配额。任何候选仍必须满足可交易、数据点时一致、价格几何完整、止损有效和禁止追价等安全边界。

## 一、A1 月度研究覆盖

### 输入

- 当月券商金股全量去重名单及推荐次数。
- 券商月度策略原文或可追溯摘要，包括宏观判断、风格、行业配置、风险与催化。
- 政策、宏观、产业周期、跨市场映射和本地基本面事实。
- 上月 A1 主题与股票覆盖，用于月初全量重建和周度增量更新。

### 双轨合同

- `institutional_coverage_pool`：券商金股作为机构覆盖种子，必须进入 A1 的 ACTIVE 或 MONITOR，不得静默丢失。
- `broker_gold_benchmark`：继续独立盲测 A1 自主研究对券商金股的自然覆盖率，不能因运行时覆盖而虚报自主命中率。

券商名单不是直接交易信号：它不能绕过事实数据、可交易性、公告风险与 A3 技术条件。名单缺少公司代码、日期或来源时只能进入数据缺口队列。

### 验收

- 当月 A 股金股去重名单覆盖率 100%，全部可追踪到 ACTIVE、MONITOR 或明确拒绝原因。
- 自主研究覆盖率与机构强制覆盖率分开报告。
- 月度策略形成 12-18 个方向、40-80 个产业节点和 200-500 只研究股票；证据不足时允许低于容量目标，但必须报告缺口。

## 二、A2 当日板块轮动

### 选择单位

A2 先选方向，再选方向内的股票，禁止用一个全局分数把所有主题混成单一排名。

1. 计算行业与概念的当日、5 日、10 日和 20 日相对强度。
2. 使用广度、成交额占比、资金流、涨停梯队、龙头结构、持续性和产业链共振判断方向状态。
3. 对每个方向计算 `rotation_rank`，保留截至收盘的 TOP3 可交易方向。
4. 每个方向分别保留龙头、中军、趋势容量和弹性候选，避免一个板块包揽全部名额。

### 生命周期

- `IGNITION/CONFIRMATION/ACCELERATION` 可进入 FOCUS。
- `REPAIR/ROTATION_IN/PERSISTENT` 可进入 FOCUS 或 WATCH，由风险标签区分。
- `DIVERGENCE/COOLING` 不直接清空；强度仍在 TOP3 时保留观察与低吸候选。
- `RETREAT/DISTRIBUTION/EXIT_RISK` 才禁止新增计划。

### 容量

- 方向：TOP3，若第 2/3 名真实不可交易则不补假方向。
- 每方向目标：FOCUS 5-12 只，WATCH 5-15 只。
- A2 下游技术评估池目标：20-60 只。

## 三、A3 三策略计划

### 共用硬边界

- 停牌、退市风险、价格/成交量无效、涨跌停不可成交。
- 放量派发、失败突破、明确日线走弱、价格几何无效。
- 止损距离超过上限、收益风险比低于最低值。
- 已闭合周线明确走弱且日线同时明确走弱。

月线和周线主要用于风险分类和 `PROBE/STANDARD`，不能要求所有低吸候选都处于多周期多头排列。

### 龙头战法

- 适用于 A2 明确的情绪龙头、早期题材和有效梯队。
- 首板观察、二三板确认；四板以上、一字板或退潮期只观察。
- A3 给出次日情景和日线失效位，A4 用封板、换手、承接和 5/15 分钟结构确认。

### 520 波段

- 日线 MA5/MA20 数据完整。
- 低吸只允许两条右侧路径：既有趋势回踩后的二波启动，或均线/价格共同确认的趋势反转。
- 二波启动要求 MA5 不低于 MA20、回踩 MA20 后重新站上 MA5，且 MA5 不再下行。
- 趋势反转要求新鲜 MA5/MA20 金叉且收盘站上两线；或重新收复 MA20 后继续站上 MA5，且 MA5 斜率转正。
- 仅触碰/收复 MA20、MA5 仍向下、收盘仍在 MA5 下方时一律只观察，禁止交给 A4 尝试抄底。
- MA20 明确下行、死叉、收复失败或放量派发仍否决。

### 趋势 5 日线

- 日线主升、有效突破、创新高或强趋势首次回踩 MA5，任一路径成立即可。
- 不再同时强制站上 MA60、完整 MA5>MA10>MA20、相对强度和平台证据全部成立。
- 过度延伸、放量跌破 MA5 或日线趋势明确走弱仍否决。

### 容量与发布

- 每日 A3 `PENDING_MORNING_REVIEW` 目标 5-20 份。
- 每份计划必须冻结唯一 A4 路由、入场参考区、不追价上限、日线失效位和盘中确认规则；A4 不得临时换策略。
- 高位加速但缺少回踩/换手承接空间的股票只能观察，不能因为创新高或趋势强直接发布追高计划。
- 超过 20 份按策略分层、方向分散和风险几何确定性截断，不按模型主观分数截断。
- 少于 5 份时必须区分：真实无机会、数据缺口、A2 方向不足或 A3 硬风险否决。

## 技术边界

- 确定性代码拥有候选覆盖、轮动排名、策略路由、价格、止损和发布状态。
- LLM 负责月度观点归纳、产业映射、事实冲突检查与遗漏核验，不得凭主观判断清空确定性合格池。
- 所有输入携带 `source_ref`、发布时间、有效月份和点时截止；回放不得读取未来名单或未来研报。
- A1 月初全量、周度增量；每日收盘仅运行 A2-A3。

## 验收矩阵

1. 9 月券商金股数据导入后，A1 覆盖追踪率 100%。
2. 至少 10 个交易日点时回放中，A2 每日最多保留 3 个方向，且各方向股票独立统计。
3. A3 每日计划中位数位于 5-20；低于 5 的交易日必须有可审计原因分布。
4. 三类策略均有非空样本；周/月非多头的低吸样本可以 PROBE，但日周共同走弱仍禁止。
5. A4 只接收 `PENDING_MORNING_REVIEW` 经早盘复核激活的计划，不连接真实交易。
6. 所有 MA520 可执行样本必须带 `second_wave_restart` 或 `trend_reversal_confirmed` 右侧证据；左侧 MA20 触碰/单日收复样本的可执行数必须为 0。

## 复审

### 第一遍：避免过度设计

- 不增加新的综合评分体系。
- A2 沿用现有事实因子，仅增加分主题排名与 TOP3 分层。
- A3 沿用三策略，不增加第四套战法。
- 不引入 Redis、消息队列或新的数据库。

### 第二遍：边界与异常

- 金股数据缺失不阻断自主 A1，但必须显示覆盖数据未就绪。
- 金股名单不能直接进入 A3；仍需经过 A2 当日轮动与 A3 技术计划。
- TOP3 是方向容量上限，不保证每天必有三个可交易方向。
- 5-20 是质量监控目标，不允许用降低止损、可交易性和未来函数约束来凑数。
