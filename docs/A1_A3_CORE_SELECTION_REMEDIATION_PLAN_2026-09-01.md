# A1-A3 核心选股逻辑与数据闭环改造方案

日期：2026-09-01
基线：`d83de613f34e5c117921bfe06f42ac4df92a0756`
范围：A1 宏观/产业与公司池、A2 题材/角色识别、A3 日线计划；A4 只消费经过类型校验的计划。本方案不连接真实交易。

## 1. 目标与不可破坏边界

目标不是增加一个更复杂的综合分，而是把实践框架变成可复现的决策链：

1. A1 回答“当前市场体制、月度产业主线以及哪些公司有基本面资格”。
2. A2 回答“截至当日哪些板块正在轮动、股票在板块中是什么角色，以及它属于情绪还是趋势”。
3. A3 回答“该类型股票是否存在适配的次日右侧计划”。
4. A4 只在盘中检查入场/退出条件，不重新解释股票类型，不跨策略路线。

必须保留的边界：

- 月度/周度结构和日线时点分开，不能因 20 日动量暂弱抹去月度产业逻辑。
- 缺数据不等于负面；缺失、源故障、字段不足、已知负面必须是四种不同状态。
- `EMOTION` 只能路由到龙头战法；`TREND` 只能路由到趋势 5 日线或 520；`UNRESOLVED` 不得形成 A4 入场计划。
- A3 的月线、封闭周线、日线负责计划资格；A4 的 15m/5m 负责盘中择时，不把未封闭 30m/60m 变成新的硬门。
- LLM 只做语义发现、证据核对和查漏补缺；确定性规则拥有筛选、类型和发布权。

## 2. 理论到代码的映射

| 实践原则 | 系统字段/规则 | 责任阶段 |
| --- | --- | --- |
| 先判断市场，再选择股票 | `market_regime` 与原型 `CYCLICAL_UPSWING/GROWTH_TREND/DEFENSIVE_QUALITY` | A1 |
| 产业周期与买入时点不是一回事 | `structural_status` + `timing_state` 双轴 | A1 |
| 系统性、结构性、基本面恶化三种回撤分开 | `pullback_cause`，基本面恶化直接风险化 | A1 |
| 行业、壁垒、财务、估值、资金、技术逐项核对 | 独立 gate/evidence，禁止用缺失项的均值冒充完整结论 | A1/A2/A3 |
| 情绪 1-3 日，趋势 1-3 周 | `stock_behavior_type`、`expected_holding_sessions` 与独立时间止损 | A2/A3 |
| 牛市回调与熊市反弹的意义相反 | `market_environment`；风险退潮禁止新开，轮动市只做已确认右侧 | A3/A4 |
| 情绪周期决定龙头路线是否可开新仓 | `emotion_cycle_stage` + `new_long_permission` | A2/A3/A4 |

| 时间止损与价格止损并列 | `time_stop_sessions` + `daily_invalidation` | A3/A4 |

## 3. A1 改造

### 3.1 市场体制与公司原型

新增无总分的原型规则：

- `CYCLICAL_UPSWING`：行业供需/价格周期与盈利方向有明确证据，负增长不能被绝对值修正为正向。
- `GROWTH_TREND`：收入/利润增长、产业空间、壁垒与现金流质量至少形成可审计组合。
- `DEFENSIVE_QUALITY`：盈利稳定、现金流覆盖、负债与估值处于可接受区间。
- `UNCLASSIFIED`：证据不足或互相冲突，只保留观察，不伪造类型。

原型决定采用哪些财务证据，不允许一套固定权重同时评价周期股、成长股和防御股。

### 3.2 月度结构与时点双轴

月度行业决策拆成：

- `structural_status`: `SUPPORTED/CONTRADICTED/INSUFFICIENT`
- `timing_state`: `ACCELERATING/PERSISTENT/COOLING/REVERSING/UNKNOWN`
- `decision`: 由二者组合得出。结构有支撑但 20 日动量降温时为 `INCLUDE_WATCH_TIMING`，不能直接 `EXCLUDE`。

政策、券商月度金股、产业供需和财务传导属于结构证据；5/10/20 日相对强弱属于时点证据。

### 3.3 财务与估值

- 财务质量输出 `available_count/required_count/missing/coverage_ratio`，覆盖不足降为观察。
- 现金流质量、利润增长方向、收入增长方向分开；负数保留符号。
- 修复估值增长比中 `abs(expected_growth)`：预期负增长不能得到成长估值奖励。
- 后续数据层要保存至少三期财报的趋势，而不是只读最后一个数。

### 3.4 硬风险

硬风险与观察风险分层：

- 硬风险：退市/重大违法/审计否定、明确不可交易、已确认严重基本面恶化。
- 观察风险：大额减持、质押异常、问询、盈利预警、长期停牌恢复等。
- 每项必须有事件日期、来源、影响范围、有效期；陈旧事件不能永久阻断。

## 4. A2 改造

### 4.1 先选板块，再定个股角色

板块保持强度 Top3，但强度由广度、持续性、梯队、资金和产业共振的可用证据组成。任一可选源故障不直接把板块变成零；核心行情/成员/日线失败才标记基础设施阻断。

### 4.2 六项角色证据

逐股保存：供应链位置、资金流、梯队结构、拥挤度、指数/产业链共振、辨识度与流动性。每项结构固定为：

```json
{
  "available": true,
  "met": true,
  "value": "...",
  "source_refs": ["..."],
  "as_of": "YYYY-MM-DD",
  "reason": "..."
}
```

缺失项进入 `data_gaps`，不自动判失败；但类型所需的关键证据不足时必须为 `UNRESOLVED`。

### 4.3 情绪与趋势互斥契约

- `EMOTION`：需要题材梯队/连板/回封/市场关注等明确情绪领导证据；允许 `LEADER_INTRADAY`。
- `TREND`：需要中期趋势、相对强度、产业逻辑或机构容量证据；允许 `TREND_MA5`、`MA520_SWING`。
- 明确梯队/连板锚点优先归为 `EMOTION`，因为次日最短周期行为拥有路由优先权；没有情绪锚点时才按中期趋势归为 `TREND`。显式声明互相冲突时仍为 `UNRESOLVED`。
- A2 输出 `stock_behavior_type`、`market_role`、`route_permission`、`conflicts` 和逐项证据。

### 4.4 情绪周期与市场多空环境

附件中的实践框架与现有市场事实一一对应，不再额外加总分：

| 实践阶段 | 确定性事实 | 新开许可 | A3/A4 动作 |
| --- | --- | --- | --- |
| 冰点 | 市场广度极弱、跌停/退潮占优 | `NO_NEW_ENTRY` | 观察，不抄底 |
| 启动 | 广度修复、涨停多于跌停、梯队种子出现 | `PROBE_ONLY` | A3 可给龙头候选，A4 只允许小试仓确认 |
| 确认/加速 | 广度、梯队和较低炸板率共同确认 | `ALLOW_CORE` | 只做真正的情绪核心 |
| 高潮 | 过热、极高梯队或一致性过强 | `NO_NEW_ENTRY` | 不新增龙头仓，已有仓进入减仓/快进快出管理 |
| 分歧/退潮 | 高炸板率或市场温度转弱 | `NO_NEW_ENTRY` | 停止新开，已有仓按退出条件管理 |

牛熊环境不通过主观文字猜测：`RISK_OFF_RETREAT` 等已确认风险状态记为 `BEAR_RISK`，持续主线记为 `BULL_TREND`，其余记为 `ROTATION_MIXED`。熊/退潮环境中的反弹不能被当成新的趋势启动；只有日线右侧结构和 A4 盘中确认同时成立才允许执行。

## 5. A3 改造

### 5.1 策略专属周期矩阵

- 龙头：月度主线不反对、封闭周线非硬空、日线处于启动/确认；不要求传统均线完美多头。
- 趋势 5 日线：月/周趋势支持或至少不反对，日线主升/首次回踩 5 日线企稳。
- 520：月/周允许波段，日线金叉、MA20 上方回踩或反转确认；避免纯左侧猜底。

封闭周线硬空且日线硬空继续统一阻断。未封闭周/月只作观察，不冒充已确认事实。

### 5.2 形态和期限

形态只作为事实标签，不再造综合分：`W_BOTTOM`、`FLAG`、`BOX_BREAKOUT`、`PLATFORM_BREAKOUT`、`NEW_HIGH_TREND`。

- 龙头：预期 1-3 个交易日，时间止损 3 日。
- 趋势 5 日线：预期 3-10 日，默认时间止损 7 日。
- 520：预期 5-20 日，默认时间止损 7 日或由显式配置覆盖。

### 5.3 情绪顶部与趋势顶部不可混用

- 情绪顶部是快速状态：炸板失去承接、放量长上影/高开低走、高潮后梯队断裂、天地板等事实出现时，龙头路线停止新开。
- 趋势顶部是慢速状态：高位放量滞涨、跌破 MA20/MA60、箱体破位、明确顶背离或死叉等事实出现时，趋势路线退出或阻断。
- 当前确定性 K 线聚合已能识别“高成交量分位 + 长上影 + 阴线”的派发组合，A3 也已有 MA20/MA60、死叉和日线弱势边界。头肩顶、三重顶和天地板只有在数据层形成可回放的明确结构后才能成为硬门，不能由模型一句描述直接制造。
- 两类顶部信号都必须保存原始行情日期、结构值和来源；缺字段为 `DATA_GAP`，不是“未见顶部”。

## 6. 逐股可追溯契约

每个阶段必须输出并持久化：

- 身份：`decision_id/symbol/name/as_of/stage/upstream_candidate_id`
- 版本：规则版本、特征版本、提示词版本、模型版本、源快照哈希
- 类型：市场体制、公司原型、板块、市场角色、情绪/趋势类型、允许路线
- 结论：状态、原因码、首个阻断门、全部失败门、数据缺口、冲突证据
- 事实：每项值、可用性、数据日期、来源引用、提取时间
- 计划：策略、前提、入场区、禁止追价、失效位、期限、时间止损、A4 条件

前端不得只展示“0 只”或“仅观察”；必须能展开看到第一阻断原因、缺失数据和上游谱系。

## 7. 数据问题解决方案

### 7.1 数据状态机

所有源/数据集统一状态：

- `READY`：日期、覆盖率和完整性满足合同。
- `STALE`：有数据但超过允许新鲜度。
- `PARTIAL`：部分标的/字段缺失。
- `SOURCE_ERROR`：请求或解析失败。
- `NOT_APPLICABLE`：该股票/策略不需要此项。
- `NEGATIVE_FACT`：数据完整且事实为负面。

只有 `NEGATIVE_FACT` 能作为负面门；前三种进入数据修复队列或降级观察。

### 7.2 来源优先级与交叉验证

- 行情/成员/分钟：同花顺为主，通达信与腾讯作字段级回补和交叉校验。
- 公告/财报：巨潮/交易所为权威源；聚合源只做索引。
- 题材与板块：同花顺分类为主，通达信/腾讯行情验证强度，不把不同分类体系直接混为同一代码。
- 资金流/梯队：能拿到真实字段才标可用；成交额不能冒充资金流，涨幅不能冒充梯队。
- 研报/月度金股：保存机构、发布日期、有效月、原文引用和股票映射；过期研究只作历史证据。

### 7.3 缓存与增量

- 事实表按 `dataset + symbol/taxonomy + trade_date + source` 幂等落盘。
- 日线增量补最新交易日；财报/基本面按公告事件增量；月初做 A1 全量，周度只更新结构证据；每天只更新 A2/A3 所需事实。
- 每次任务先生成 readiness manifest，再执行筛选；不满足合同就报告具体缺口，不启动无意义的 LLM 批次。

## 8. 验收矩阵

### 8.1 单元/契约测试

- 负预期增长不能获得正向估值奖励。
- 财务覆盖不足与真实财务差分开。
- 三种回撤原因及未知状态可复现。
- 情绪/趋势类型互斥，冲突与缺数据不生成计划。
- 情绪周期在启动/确认/加速允许试仓或核心路线，在高潮/分歧/退潮/冰点阻断新的龙头计划；该门不误伤独立成立的趋势路线。
- 三种 A3 策略只接受各自允许的类型。
- 未封闭周期不会冒充确认，硬空组合仍阻断。

### 8.2 集成测试

- A1→A2→A3 的 `upstream_candidate_id`、原因码、源引用连续。
- A2 数据源单点失败时，记录降级但不把全池判成真实无机会。
- A3 每个非空计划都有入场、禁止追价、失效位、期限和 A4 路由。
- 前端详情接口能区分 `DATA_GAP`、`NO_OPPORTUNITY`、`REJECTED`。

### 8.3 历史验证

- 至少 10 个交易日点时回放，严格使用当时可得数据，防未来函数。
- 分类统计情绪与趋势：计划数、触发率、失效率、最大不利变动、最大有利变动、时间止损比例。
- 工程测试通过不等于策略有效；只有历史样本与后续模拟盘数据达到验收标准才发布效果结论。

## 9. 两轮方案复审

### 复审一：删除过度设计

- 不新增统一总分、不引入向量库或 Redis 作为本轮前置条件。
- 不把 30m/60m 设为 A4 新硬门。
- 不在 A1-A3 实现组合仓位管理，组合约束仍由运行时风险层负责。
- 不实现头肩顶/三重顶等未经点时样本验证的复杂形态识别器；本轮只消费已有确定性事实，避免形态过拟合。

### 复审二：边界与异常

- 旧快照缺新字段时必须兼容读取，但发布计划采用保守的 `UNRESOLVED`。
- 可选数据缺失只能降级；关键身份/行情/日期缺失才阻断。
- 模型结论不能覆盖确定性类型与路由；模型否决必须带引用，模型赞成不能绕过门。
- 本轮仅修改和验证本地代码；推送、部署、重跑生产任务需单独执行并核验目标提交。
